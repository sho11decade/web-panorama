# web-panorama

スマートフォンのカメラアプリで撮影したパノラマ写真のビューワーソフト

## 機能

- **パノラマ表示**: Three.js / WebGL を使った円柱面マッピングで水平パノラマを滑らかに表示
- **ドラッグ操作**: マウスドラッグ（PC）・タッチスワイプ（スマホ）で視点を自由に移動
- **ズーム**: マウスホイール / ピンチ操作でズームイン・アウト（FOV 30°〜120°）
- **慣性スクロール**: フリック後に自然に減速する慣性操作
- **キーボード対応**: 矢印キーで視点移動
- **ファイル読み込み**: ファイル選択ダイアログまたはドラッグ＆ドロップ
- **全画面表示**: ワンクリックで全画面モードに切り替え
- **完全オフライン動作**: サーバー送信なし、すべてブラウザ上で完結

## 対応環境

| 種別 | 対象 |
|------|------|
| ブラウザ | Chrome / Firefox / Safari / Edge（最新版） |
| デバイス | PC（Windows / macOS）、スマートフォン（iOS / Android） |
| 画像形式 | JPEG / PNG（スマートフォン撮影の水平パノラマを推奨） |

## 開発環境のセットアップ

```bash
npm install
npm run dev      # 開発サーバー起動 → http://localhost:5173/
npm run build    # プロダクションビルド
npm run preview  # ビルド結果のプレビュー
```

## 技術スタック

- [Three.js](https://threejs.org/) — WebGL レンダリング（円柱面マッピング）
- [Vite](https://vitejs.dev/) — ビルドツール
- TypeScript — 型安全な実装
